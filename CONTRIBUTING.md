# Contributing

Thanks for your interest in contributing to this project! We welcome improvements, bug fixes, documentation enhancements, and new examples.

Please follow these steps to contribute:

1. Fork the repository and create a new branch from main:

```bash
git checkout -b feature/my-change
```

2. Make your changes in a branch with a clear, small scope. Add tests where appropriate.

3. Run tests locally:

```bash
pytest
```

4. Format code and run linters (if applicable):

```bash
# Example using black
black .
```

5. Commit with a clear message. We follow conventional commits for commit messages, e.g. `fix:`, `feat:`, `docs:`.

6. Push your branch and open a pull request against `main` with a descriptive title and summary of changes.

Guidelines

- Keep changes focused and pull requests small.
- Document new features or public functions in the README or docstrings.
- If your change affects the public API, describe the impact in the PR body.

Code of Conduct

Be respectful and follow GitHub community guidelines. If you would like a formal Code of Conduct added, open an issue and we can add one.

Maintainer contact

If you need urgent help, open an issue and tag @Theofil87.
